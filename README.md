# 🧟 Call of Duty: Zombies 2D — Бункер и Жёсткая Лудка

Браузерный 2D-шутер на выживание в духе **Call of Duty: Zombies** (*Nacht der Untoten*) с полноценным сенсорным управлением для смартфонов, системой мем-рекламы (фото и видео) и **Жёсткой Лудкой 777**.

Проект работает полностью автономно на чистом JavaScript (ES6 Modules) + HTML5 Canvas + Web Audio API без внешних зависимостей и сборщиков — готов к деплою на GitHub Pages.

---

## 🕹 Управление

### 💻 На ПК (Клавиатура + Мышь)
| Клавиша | Действие |
|---|---|
| **W, A, S, D** / Стрелки | Перемещение |
| **Shift** (удержание) | Спринт (расходует стамину) |
| **Мышь** | Прицеливание и фонарик |
| **ЛКМ** | Стрельба |
| **R** | Перезарядка |
| **F** | Взаимодействие (двери за очки, оружие со стены, Mystery Box, Мем-ТВ) |
| **1, 2, Q** или **Колесико** | Смена оружия |
| **G** | Мем-реклама → Жёсткая лудка |
| **H** | Срочный **ДОДЕП** (появляется при ходьбе, действиях и смерти) |
| **L** | Таблица лидеров и PostgreSQL БД |
| **Tab** (удержание) | Таблица статистики |
| **M** | Включить / выключить звук |
| **Esc** / **P** | Пауза и правила лудки |

### 📱 На смартфонах и планшетах
- Левая половина экрана — виртуальный аналоговый джойстик.
- Правая половина экрана — прицеливание и стрельба.
- Экранные кнопки для огня, перезарядки (`R`), взаимодействия (`F`), смены оружия (`Q`) и спринта (`RUN`), а также кнопки мем-рекламы/лудки и всплывающего ДОДЕПА в правом верхнем углу.

## 📺 Жёсткая Лудка 777, Система Додепа и Орда врагов

1. **Просмотр мем-рекламы и Жёсткая Лудка**:
   - Нажмите **`[G]`**, кнопку **`📺 МЕМ-РЕКЛАМА → 🎰 ЛУДКА`** на экране или подойдите к терминалу **777 МЕМ** в крыльях бункера (`[F]`).
   - В пуле используются только встроенные фото- и видео-мемы проекта (`src/config/memeAds.js`).
   - **Пониженные шансы выигрыша**: джекпот 777 (~2.5%), легендарное оружие (~4.5%), пустые прокруты и жёсткий скам, а докрут x2 работает с риском **30% победы против 70% скама**!
2. **Система ДОДЕПА (`[H]`)**:
   - Всплывает **при ходьбе по бункеру**, **во время боевых действий** (перезарядка, убийства, трата очков, низкое HP) и **при смерти** на экране Game Over для экстренного докрута/возрождения.
3. **Огромный бункер и 13 видов врагов**:
   - Расширенная карта `2800×2000` (Стартовый бункер, Центральный арсенал, Восточный ангар, Северный реактор, Зал Лудки 777) и волны с Плевунами, Камикадзе, Щитоносцами, Хим-мутантами, Фантомами, Крикунами, Некромантами и Альфа-Боссами.

## 🐘 Локальный запуск с PostgreSQL БД

Для запуска игры вместе с локальным Node.js API-сервером и базой данных **PostgreSQL** (`blinov_zombies`):

```bash
./start-local.sh
```

Либо вручную:

```bash
npm install
npm start
```

Откройте `http://localhost:3000/` в браузере (поддерживаются переменные `PGHOST`, `PGPORT`, `PGUSER`, `PGDATABASE`, `PGPASSWORD`, `DATABASE_URL`, `PORT`).

### 🌐 GitHub Pages + подключение своей БД
- Статический фронтенд можно деплоить прямо на **GitHub Pages** (`.github/workflows/deploy.yml`) — без сервера он автоматически работает через `localStorage`.
- Чтобы «прикрутить» к GitHub Pages работающий бэкенд с PostgreSQL, передайте URL API в параметре `?api=http://localhost:3000` (или `https://ваш-api-домен`) либо введите его в окне **`🏆 ТОП [L]` → URL API сервера**.
- При открытии `index.html` напрямую с диска (`file://`) используется встроенный совместимый загрузчик `src/bundle.classic.js`, чтобы игра запускалась даже без локального HTTP-сервера.


## Публикация на GitHub Pages и мультиплеер

1. Загрузите проект в репозиторий GitHub, включая папку `memes`, и отправьте изменения в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages → Build and deployment** и выберите источник **GitHub Actions**. Workflow соберёт и опубликует игру.
3. Для сетевой игры запустите `npm start` на компьютере-хосте и предоставьте его порту 3000 публичный HTTPS-адрес (например, через Cloudflare Tunnel). GitHub Pages сам сервер не запускает.
4. Откройте опубликованную игру, нажмите «Совместная игра», укажите HTTPS-адрес сервера, имя и название комнаты, затем создайте комнату. Отправьте другу ссылку из меню: в ней сохранены адрес сервера и название комнаты. Сервер и туннель должны оставаться запущенными.

Адрес временного туннеля может измениться при перезапуске; тогда обновите его в меню игры и отправьте новую ссылку.
