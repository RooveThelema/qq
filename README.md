# Последний рубеж

Браузерный **survivors-like / bullet heaven**: двигайся, уходи от орды, собирай опыт и выбирай улучшения. Оружие само находит цель и стреляет. Выбирай вылазку на 10 минут, экспедицию на 20 минут (по умолчанию) или бесконечную ночь. В конечных режимах нужно также уничтожить всех Стражей.

Главный режим — **кооператив до 10 игроков через интернет**. Сервер рассчитывает общий бой: врагов, попадания, опыт, улучшения, смерть и помощь товарищу. Есть и одиночный режим, работающий без сервера. Мемы, реклама и казино отключены: старые медиафайлы не подключаются и не раздаются игровым сервером.

## Играть с другом без VPS

Нужны Node.js 20+ и SSH. На Linux/macOS SSH обычно установлен. Другу нужен только современный браузер на компьютере или телефоне.

В папке проекта:

```bash
npm ci
npm run share
```

Или `./start-local.sh --share` — проверит зависимости и запустит всё сам.

Команда собирает игру, запускает сервер и открывает **бесплатный HTTPS-туннель Serveo без регистрации и личных SSH-ключей**. Публичная ссылка появится в терминале:

```text
ИГРА ДОСТУПНА В ИНТЕРНЕТЕ
https://…serveousercontent.com
```

1. Открой эту публичную ссылку сам. Выбери имя, героя, локацию и создай комнату.
2. Скопируй приглашение из комнаты и отправь другу или преподавателю.
3. Друг открывает ссылку, вводит имя, выбирает героя и входит. Код комнаты уже будет в ссылке.
4. Участники отмечают готовность. Командир запускает забег.

Можно открыть игру у себя по `http://localhost:3000/`: приглашение автоматически использует адрес активного туннеля. Если создал комнату до запуска туннеля — скопируй ссылку заново после его запуска.

**Компьютер хоста и терминал с `npm run share` должны оставаться включёнными.** Ctrl+C закрывает туннель и сервер, запущенный этой командой. Уже работающий отдельно сервер команда не останавливает. Бесплатный адрес временный и иногда меняется; лаунчер печатает новый адрес и обновляет его в игре. При обрыве SSH переподключается автоматически; если адрес изменился, отправь новое приглашение. При первом открытии Serveo может показать свою страницу с кнопкой Continue — нажми её, чтобы перейти к игре.

Повторная команда `npm run share` **остаётся в терминале** и показывает состояние уже работающего туннеля. Это монитор: Ctrl+C завершает только монитор, исходный туннель продолжает работать. Прямо в этом окне введи `r` или `--restart` и нажми Enter — монитор перезапустит туннель и станет его новым хозяином. Команда `url` показывает актуальную ссылку, а `--provider=pinggy` переключает маршрут. Если окно было открыто до обновления лаунчера, сначала нажми Ctrl+C и снова выполни `npm run share`.

Полную команду npm вводи в обычной строке терминала после Ctrl+C:

```bash
npm run share -- --provider=serveo --restart
```

Лаунчер проверяет команду и папку старого процесса перед остановкой; посторонние процессы не трогает. Если запущен сервер старой версии, обычный запуск покажет понятную ошибку. Команда с `--restart` обновит его автоматически только после проверки принадлежности проекту и занятого игрового порта; иначе попросит закрыть прежний запуск через Ctrl+C.

Если сайт не открывается без VPN, грузится частями или долго не отвечает, попробуй другой маршрут. Доступность зависит от сети обоих игроков; проверка с одного компьютера не доказывает доступность у каждого провайдера в РФ.

```bash
npm run share -- --provider=pinggy --restart
```

Доступные провайдеры:

| Значение | Назначение |
| --- | --- |
| `serveo` | По умолчанию. SSH через порт 443, затем 22. Бесплатный временный HTTPS-адрес; возможна страница Continue при первом открытии. |
| `pinggy` | Альтернативный маршрут через SSH-порт 443. Бесплатная сессия примерно на час, затем новая ссылка; возможна страница Visit Site. |
| `localhost` | Прежний localhost.run / lhr.life. Используй только если этот домен доступен вам обоим. |
| `cloudflare` | Явный выбор при установленном cloudflared. Автоматически не включается: его доступность в РФ также зависит от провайдера. |

Если Serveo недоступен при обычном запуске без флага провайдера, лаунчер пробует Pinggy. **Cloudflare и localhost.run автоматически не выбираются.** Любой провайдер можно указать явно:

```bash
npm run share -- --provider=localhost --restart
npm run share -- --provider=cloudflare --restart
```

Для последнего нужен установленный `cloudflared`; при необходимости укажи путь через `CLOUDFLARED`. Для другой локальной программы на порту 3000 выбери свой порт:

```bash
PORT=3001 npm run share
```

Используются инструкции провайдеров: [Serveo](https://serveo.net/docs/), [Pinggy](https://pinggy.io/docs/), [localhost.run](https://localhost.run/docs/faq#i-dont-want-to-use-an-ssh-key). Сервер раздаёт только игровые HTML/CSS/JS/SVG; `.env`, база, Git, отчёты и личные медиа недоступны по публичной ссылке.

## Локальный запуск и одна Wi-Fi-сеть

```bash
npm ci
npm start
```

Открой `http://localhost:3000/`. Для друга в той же сети нужен LAN-адрес компьютера хоста (он отображается в справке подключения), например `http://192.168.1.10:3000/`. Разреши входящие подключения для Node.js в локальном брандмауэре. Для разных сетей используй `npm run share`.

VPS нужен только если хочешь собственную постоянную ссылку, работающую круглосуточно независимо от домашнего компьютера. Для текущего туннеля он не нужен.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD или стрелки; физические клавиши работают и в русской раскладке |
| Стрельба и выбор цели | Автоматически |
| Рывок | Пробел / Shift; перезарядка 4 секунды |
| Взаимодействие | E рядом с объектом или кнопка на экране |
| Метка отряду | Q или кнопка ⌖; видна союзникам 4 секунды |
| Улучшение | Выбрать одну из трёх карточек при повышении уровня |
| Пауза / меню | Esc |
| Телефон | Виртуальный джойстик и кнопка рывка |

В кооперативе меню и выбор улучшения не останавливают общий бой. Чтобы поднять павшего товарища, стой рядом с ним три секунды. Если вся команда погибла — забег окончен. При коротком обрыве связи или обновлении страницы игрок может вернуться в течение 30 секунд; если командир отключился, управление комнатой получает другой подключённый участник.

Если WebSocket не подключается или перестаёт отвечать, игра автоматически пробует резервное соединение по HTTP. В лобби оно обозначено как «Резервное соединение». Принудительная проверка этого режима: добавь `?transport=http` к адресу игры. Состав отряда и готовность регулярно сверяются с сервером, поэтому пропущенное обновление не оставляет хозяина с устаревшим списком участников. Кнопка «Повторить» восстанавливает соединение; повторные запросы не создают второго игрока.

Приглашения содержат код комнаты и в параметре, и после `#`: это сохраняет приглашение, когда страница Continue у туннеля очищает параметры адреса. Отправляй другу ссылку целиком. После обновления серверной версии обновите страницы и создайте новую комнату.

## Что есть в игре

- Три открытые арены с широкими путями отхода: комплекс «Рубеж-09», заражённый лес «Тихая чаща», пустошь «Мёртвый сигнал».
- Пять героев: Следопыт, Инженер, Проводник, Искра (скорость, криоген и сбор опыта) и Часовой (здоровье и лазер).
- Восемь видов оружия: импульсная винтовка, орбитальные дроны, энергокольцо, цепная молния, ракеты, криоген, пробивающий лазер и контактные мины.
- Восемь эволюций: оружие V уровня + соответствующее пассивное улучшение III уровня автоматически усиливают оружие. Рецепт виден на карточке.
- Три режима: вылазка (10 минут), экспедиция (20 минут) и бесконечная ночь с боссом каждые две минуты. Режим выбирает создатель комнаты; повторный забег сохраняет его.
- Восемь объектов на каждой арене: тайники с улучшениями для каждого, медстанции с общим лечением, турели на 25 секунд и обелиски, вызывающие элиту за награду. Станции и обелиски имеют перезарядку.
- Случайные задания без одинаковых подряд: удержание ретранслятора (вдвоём вдвое быстрее), уничтожение орды и поиск припасов. За успех — опыт, лечение и улучшение каждому. Провал задания не завершает забег.
- Удары по арене с предупреждением за 2,7 секунды: красные зоны опасны и для игроков, и для врагов. Цели заданий и метки отряда видны на миникарте и через указатели за краем экрана.
- Улучшения оружия и пассивных характеристик: урон, скорость атак и движения, HP, магнит опыта, броня и регенерация.
- Обычные заражённые, быстрые ловчие, громилы, плевуны, тараны, носители (распадаются на трёх ловчих), регенераторы (лечат орду), элиты с золотой обводкой и боссы; сложность растёт со временем и числом игроков.
- Общий опыт команды, личные сборки, помощь павшим, результат команды и новый забег в той же комнате.
- Серверная таблица результатов без обязательной базы данных.

## Проверки

```bash
npm test
npm run check
npm run build:classic
node scripts/benchmark.mjs
```

Автотесты запускают настоящий HTTP/WebSocket-сервер и несколько клиентов: создание/вход, готовность, одинаковые снимки общего мира, ограничение ввода, опыт и выбор улучшений, переподключение, смена командира, лимит комнаты в 10 игроков, удаление пустой комнаты, сохранение результата и повторный забег. Отдельно проверяются карты, все восемь видов оружия, опыт, рывок, возрождение и цель забега.

Для проверки уже запущенного публичного адреса с двумя клиентами:

```bash
npm run test:online -- https://твой-публичный-адрес
```

Проверка создаёт отдельную тестовую комнату, подключает второго игрока, начинает забег, проверяет общий мир и движение, затем удаляет только свою комнату.

## Как устроен проект

- `src/game/catalog.js` — герои, оружие, враги, улучшения и арены.
- `src/game/World.js` — симуляция боя, общая для сервера и одиночного режима.
- `src/ui/` — отрисовка и сетевой клиент.
- `src/main.js` — интерфейс, управление и переключение режимов.
- `server.js` — HTTP, WebSocket, комнаты и сохранение результатов.
- `scripts/share.mjs` — запуск сервера и бесплатного интернет-туннеля.
- `tests/` — проверки симуляции и реального сетевого протокола.

### Производительность

- Поиск цели без сортировки, пространственная сетка для попаданий снарядов, быстрые проверки квадратов расстояний и индекс целей для ракет. Сетка учитывает отбрасывание врагов в том же шаге.
- Компактные полные сетевые кадры согласуются при подключении; старый формат остаётся доступен старым клиентам. Потерянный кадр не требует восстановления цепочки изменений. Сериализация переиспользуется между игроками одной комнаты; HTTP-сжатие выполняется асинхронно.
- HTTP-резерв отправляет следующий запрос сразу после медленного ответа, а на быстрой сети держит период около 66 мс. Неизменившееся направление отправляется реже с регулярным подтверждением активности.
- Интерполяция между снимками и ограниченное предсказание движения на 100 мс при задержках пакетов. Состояние боя остаётся на сервере.
- Фон арены кэшируется. Разрешение Canvas ограничено, сортируются только видимые объекты. В меню Esc есть экономная графика с упрощённой отрисовкой врагов и DPR 1.
- Одиночная симуляция идёт с фиксированным шагом 30 Гц, независимо от частоты кадров экрана. Лимиты орды (260), снарядов (700), кристаллов (300) и эффектов (100) сохраняются в бесконечном режиме.

`node scripts/benchmark.mjs` запускает воспроизводимый сценарий с четырьмя бойцами, 250 врагами и шестью полностью улучшенными видами оружия. Он выводит медиану и p95 времени шага с сериализацией каждого второго снимка, а также размер обычного/компактного JSON и gzip. Это измерение локального CPU и пакета, а не FPS браузера или задержки интернет-туннеля.

Сервер работает на 30 шагах симуляции в секунду и рассылает общие снимки мира 15 раз в секунду. Клиент отправляет направление движения и выбор улучшения; координаты, HP и убийства рассчитываются сервером. Токен возвращения хранится только в `sessionStorage` вкладки.

Результаты сохраняются в `data/scores.json`. Если задана `DATABASE_URL`, завершённые командные забеги дополнительно записываются в PostgreSQL (`survivor_runs`); игра запускается и без PostgreSQL. Старые таблицы базы сохраняются. Переменные окружения показаны в `.env.example`; передавай их окружением процесса (файл `.env` автоматически не загружается).

`npm run build:classic` создаёт `src/bundle.classic.js` для одиночной игры через `file://`. Обычный запуск через сервер использует ES-модули. GitHub Pages подходит только для одиночной статической версии: для кооператива открывай ссылку на работающий сервер/туннель.

Старые `REPORT.md` / `REPORT.docx`, скриншоты и медиа сохранены как материалы предыдущей версии; описание текущей реализации находится в этом README.


### Свободная сборка и более медленная прокачка

Для повышения уровня нужно `25 + 12 × уровень + 2 × уровень²` XP: сначала 39, затем 57, 79, 105… вместо прежних 13, 18, 23, 28. Опыт остаётся общим; награды за задания и тайники по-прежнему дают дополнительные улучшения.

Все восемь видов оружия и семнадцать пассивных навыков можно взять одновременно. Лимитов слотов и уровней улучшений нет: после V уровня оружие продолжает усиливаться, эволюция сохраняется. Десять новых навыков: Меткий глаз, Жестокость, Вампиризм, Шипы, Уклонение, Второе дыхание, Резонанс, Баллистика, Добивание и Полевой спасатель. Шанс критического удара и уклонения растёт с убывающей отдачей. Жестокость усиливает криты, поэтому сочетается с Метким глазом. Количество снарядов в залпе, дронов и переходов молнии ограничено ради производительности; урон продолжает расти с уровнем оружия.

В HUD видны числовые уровни оружия и список всех взятых навыков. Комнаты вмещают до десяти бойцов; список отряда прокручивается, а общий лимит врагов сохраняется.
